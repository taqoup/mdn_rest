# Мыс Доброй Надежды — страница отзывов

Статическая страница на русском языке по предоставленному образцу. Исходное первое изображение используется целиком, без обрезки. Текст, декоративные рамки и кнопки — отдельные элементы HTML/SVG. Название уменьшено и размещено ниже маяка; подпись «ресторан • Кронштадт» удалена. Заголовок «Поделитесь впечатлением» уменьшен. Над кнопками размещено «Спасибо за ваше путешествие с нами». Дополнительная благодарность и подпись TAQO удалены. Текст выполнен в тёмно-коричневом цвете со светлой мягкой тенью для читаемости на фоне карты. На телефонах вся композиция подстраивается под видимую высоту экрана без прокрутки.

## Просмотр

Откройте `index.html` в браузере. Сборка, установка пакетов и сервер не нужны. Для локального HTTP-просмотра: `python3 -m http.server 8000` в этой папке.

## Размещение

Загрузите `index.html`, `styles.css` и папку `assets` в корень статического сайта, сохраняя их относительные пути. Страница совместима с GitHub Pages и размещением в подпапке. Для GitHub Pages выберите ветку и папку с этими файлами в Settings → Pages.

Репозиторий проекта: https://github.com/taqoup/mdn_rest. Файлы страницы размещаются в корне репозитория. Публикация через GitHub Pages настраивается отдельно в Settings → Pages: Deploy from a branch → main → / (root).
